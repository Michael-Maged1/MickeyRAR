# أفكار التحسين — Mickey RAR

## P0 (ضروري)
1. عربية RTL كاملة، ومحاذاة الصفوف والنوافذ والاختصارات مع دعم اختلاط العربية بالأرقام والمسارات الإنجليزية.
2. تشغيل غير متزامن للضغط والاستخراج مع تقدم حقيقي وإلغاء آمن.
3. اختبارات round-trip وSHA-256 عبر أنظمة التشغيل؛ وتحليل ملفات أرشيف خبيثة/معطوبة في بيئة معزولة.
4. وضع آمن لاستخراج الأرشيف إلى مجلد مع تحذير عند استبدال الملفات ومنع مسارات الخروج خارج الوجهة.

## P1 (تجربة مستخدم)
5. تقدير وقت وحجم الضغط؛ وSmart Preset بناءً على نوع الملفات.
6. معاينة ملفات دون استخراج الكل (مع حدود حجم وأمان واضحة).
7. مدير طابور مهام ومحدد استهلاك CPU/RAM.
8. قائمة بالضغط الحديث وبحث داخل أسماء ملفات الأرشيف.

## P2 (ميزة تنافسية)
9. مقارنة مستويات الضغط بأرقام فعلية على عينة آمنة قبل إنشاء الأرشيف.
10. فحص سلامة SHA-256 وتصدير تقرير تحقق.
11. وضع Split Archive للملفات الكبيرة والمشاركة عبر الشبكة.
12. تحديثات موقعة وتوزيعات مناسبة للأنظمة الثلاثة.

## تسمية المنتج
اسم العرض: Mickey RAR. الاسم التقني: `mickey-rar`.
تنبيه: استخدام RAR في الاسم قد يثير التباسًا مع علامة WinRAR؛ يُنصح بمراجعة العلامات التجارية قبل التوزيع التجاري.
