# Mickey RAR — سجل الاختبارات v0.3.0

## حدود التحقق
- الفحوص المنفذة في بيئة الإنشاء: وجود ملفات المشروع، اتساق إعدادات Ultra، اكتمال سلاسل الواجهة بالعربية والإنجليزية، فحص سلامة ZIP.
- غير منفذ: `cargo test` و `cargo build` وعمليات 7-Zip الحقيقية بسبب غياب Rust toolchain و7zz/7z في بيئة التشغيل.
- اختبارات Rust المضافة لملف `src/engine.rs`: إعدادات Ultra، وضع non-solid، عدد threads خارج النطاق، مدخلات فارغة، أسماء بمسافات؛ ولـ `src/i18n.rs`: التبديل بين اللغات.

## طريقة اختبار فعلي على جهاز المطور
1. ثبّت Rust و7-Zip وأضف `7zz` إلى PATH.
2. شغّل `cargo fmt -- --check` ثم `cargo test` ثم `cargo build --release`.
3. شغّل `cargo run` وأنشئ ملفًا نصيًا/ملفًا ثنائيًا/مجلدًا بحروف عربية.
4. اضغط إلى 7z واختبر الأرشيف ثم استخرجه وقارن SHA-256 لكل الملفات.
5. بدّل اللغة إلى العربية ثم الإنجليزية، وأغلق التطبيق وافتحه للتأكد من حفظ التفضيل.
6. راجع الواجهة بصريًا على Windows وmacOS وLinux؛ اختبر الخط العربي والمحاذاة واختلاف DPI.

## ملاحظات وأولويات إصلاح قبل الإصدار العام
- تشغيل أوامر 7-Zip حاليًا متزامن على مسار UI، وقد يجمّد الواجهة أثناء الضغط الكبير. **أولوية حرجة**: worker/background + progress + cancel.
- يجب اختبار/منع path traversal والروابط الرمزية والأرشيفات غير الموثوقة قبل الاستخراج.
- العربية مترجمة في الواجهة الأساسية، لكن **انعكاس RTL الكامل** وبعض رسائل الأخطاء وحوارات النظام لم يُستكمل بعد.
- القائمة العلوية تمثيل بصري وليست Menu أصلية؛ وأزرار إضافية من WinRAR لم تنفذ.
- لا يدعم إنشاء RAR، وإنما استخراج RAR عبر 7-Zip حين يتاح ذلك.
