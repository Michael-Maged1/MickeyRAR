# Mickey RAR — المواصفات الملزمة للواجهة (Design Lock v0.5.0)

**مصدر الحقيقة المرئي:** `assets/approved-ui-reference.png`، وهو **نفس ملف الصورة الذي رفعه المستخدم في آخر رسالة**، لا صورة مولدة بالبحث أو وصف بديل. أبعاد المرجع: **1448×1086** بكسل. SHA-256: `fa97966b6ac266e9aa192c3b521021891e632fa49328c2bb3f8573800981afc4`.

## 1. قواعد لا تُغيَّر

- اسم التطبيق في شريط العنوان: **Mickey RAR** مع أيقونة **كتب أرشفة صغيرة أصلية** على اليسار.
- **English** هي اللغة الافتراضية عند أول تشغيل؛ **Arabic** متاحة من Options / Language مع حفظ الاختيار. عند العربية تنعكس محاذاة العناصر القابلة للانعكاس، ولا تُقلب الأرقام أو مسارات الملفات قسرًا.
- الخلفية سوداء/فحمية؛ النص رمادي فاتح؛ الأخضر **مطفي مائل للزيتوني** وباستخدام منخفض في العناصر المحددة فقط. ممنوع توهج neon أو التدرجات الصارخة.
- **لا** بانر، لا شعار ضخم، لا صناديق حول كل زر في الـToolbar. أيقونات صغيرة مع تسمية أسفلها وفواصل رفيعة.
- الواجهة كلاسيكية مثل تقسيم برامج أرشفة الملفات؛ لا نسخ للأصول المحمية الخاصة ببرامج أخرى.

## 2. تقسيم الصورة المرجعية (1448×1086)

| العنصر | موضع تقريبي بالبيكسل | السلوك المطلوب |
|---|---|---|
| Title bar | y=0–56 | الأيقونة الصغيرة والاسم وأزرار النافذة الأصلية للنظام |
| Menu bar | y=57–102 | File / Commands / Tools / Favorites / Options / Help |
| Toolbar | y=103–208 | Add / Extract / Test / View / Delete / Find / Wizard / Info / Repair، بدون بطاقات مربعة |
| Navigation bar | y=209–281 | Back, Forward, Up, Address field |
| Content | y=282–989 | Sidebar يسار بحدود x≈10–309، جدول الملفات يمين x≈319–1397 |
| Table headers | y=292–338 | Name / Size / Packed / Type / Modified / CRC |
| Bottom status | y=990–1042 | اختيار المستخدم، الإجمالي، نوع الأرشيف |

هذه القياسات **للاسترشاد في التطابق البصري** وليست قيودًا صلبة؛ يجب استخدام layout مرن للتصغير والتكبير وDPI المختلفة، مع اختبار 100% و125% و150%.

## 3. جدول الملفات

- أعمدة قابلة للتغيير والفرز: Name, Size, Packed, Type, Modified, CRC.
- صف واحد محدد بلون أخضر زيتوني شفاف وخط مقروء؛ عدم تلوين كامل الجدول.
- أيقونات ملفات ومجلدات صغيرة، محاذاة أحجام الملفات إلى اليمين، ومسارات Unicode سليمة.
- حالات فارغ/تحميل/خطأ/كلمة مرور واضحة؛ دبل كليك على المجلد للدخول وعلى الأرشيف لعرض محتواه.

## 4. اللغات وإمكانية الوصول

- مفاتيح الترجمة لجميع النصوص والأخطاء وأسماء الأزرار؛ لا تخلط العربي والإنجليزي في النص الافتراضي.
- واجهة عربية RTL مع إبقاء الأرقام وأسماء الملفات والمسارات كما هي؛ اختبار الملفات ذات أسماء عربية وفارسية ورموز Unicode.
- تنقل لوحة المفاتيح: Tab, Shift+Tab, Enter, Esc, Ctrl+A, Delete؛ دعم focus indication وتباين النص/الخلفية.
- اختيار الخط بحسب المنصة مع fallback يدعم Arabic shaping؛ اختبار عدم قطع النصوص.

## 5. قواعد مطابقة نهائية

1. الصورة المرجعية المرفوعة هي المرجع، وليس أي Image Search أو تصميم مولَّد لاحقًا.
2. مقارنة screenshot فعلي للتطبيق بالمرجع على شاشة 1448×1086، ثم اختبار أحجام أصغر.
3. أي زر غير جاهز يكون **disabled** مع تفسير موجز، ولا يدّعي العمل.
4. أي تغيير ألوان أو تموضع رئيسي يُعامل كتغيير تصميم ويحتاج موافقة المستخدم.
5. برنامج Rust + Slint متعدد المنصات، وتجهيز نسخ Windows/macOS/Linux منفصلة عند اجتياز الاختبارات.
