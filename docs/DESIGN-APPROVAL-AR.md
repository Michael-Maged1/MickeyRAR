# واجهة Mickey RAR المعتمدة

- الاعتماد: الشكل الأخير الذي اختاره المستخدم، تصميم Classic بسيط على طريقة تقسيم WinRAR.
- اللغة الافتراضية: English، مع خيار العربية، ويُحفظ اختيار المستخدم.
- الألوان: فحمي وأسود هادئ مع أخضر Lime باهت قليل التشبع دون توهج.
- شريط الأدوات: بدون بطاقات أو مربعات منفصلة أو صورة زخرفية كبيرة.
- الأيقونة: كتب أرشفة متراكبة بتصميم أصلي، وليس استنساخ شعار WinRAR.
- المرجع المرئي: `assets/approved-ui-reference.png`، وهو نموذج تصميم وليس لقطة من البرنامج المبني.
- الوظائف غير المكتملة (Repair, Wizard, Find, Delete داخل الأرشيف) يجب ألا تُعرض كمكتملة.

**ملاحظة تنفيذية:** توافق Slint الفعلي، واختبار RTL الكامل، ومطابقة التصميم بصرياً تحتاج تشغيل التطبيق وتجميعه على أنظمة التشغيل المستهدفة.
