# مواصفات ArchiveDesk Classic

## الهدف
تطبيق ضغط ملفات أصلي متعدد الأنظمة باستخدام Rust وSlint، يحافظ على تقسيم واجهة WinRAR الكلاسيكية دون نسخ شعاراته أو ملفاته المحمية.

## الأنظمة
Windows 10/11, macOS (Intel/Apple Silicon), Linux x86_64. يتم بناء الحزم لكل نظام على حدة.

## بنية المنتج
- ui: مكونات Slint وتخطيطات الواجهة.
- application: عمليات اختيار الملفات، التحقق، قائمة المهام، واختصارات لوحة المفاتيح.
- archive_engine: واجهة مستقلة لمحركات 7-Zip أو المكتبات الآمنة.
- platform: تكامل Explorer/Finder/Linux desktop.
- tests: عينات ضغط سليمة وتالفة وملفات ضخمة، واختبارات أمن المسارات.

## المرحلة 1 (النموذج المرفق)
استعراض مجلدات + فتح قائمة محتويات الأرشيف + إنشاء أرشيف من ملفات مختارة + فك الضغط + اختبار سلامة الأرشيف.

## المرحلة 2
عمليات بالخلفية وإلغاء وتتبع التقدم، أعمدة ملف شاملة، قائمة كاملة، إعدادات الاختصارات، كلمات مرور.

## المرحلة 3
فصل الصيغ واختيار مستويات الضغط، تجزئة الملفات، البحث، السحب والإفلات، معاينات آمنة.

## المرحلة 4
اختبارات أمنية، تثبيت وتوقيع وCI لكل منصة، تكامل النظام ومراجعة التراخيص.

## معايير قبول الإصدار 1.0
عمليات واضحة بدون تجمد للواجهة، سجل أخطاء قابل للتشخيص، استخراج آمن، ملفات كبيرة، فشل قابل للاسترداد، اختبارات آلية، وتثبيت مدعوم لكل نظام.
